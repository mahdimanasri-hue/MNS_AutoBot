# MNS v2
نسخه آماده برای استقرار اولیه.

## Render
Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`

Environment Variables:
- `BOT_TOKEN` = توکن BotFather (محرمانه)
- `WEBHOOK_URL` = آدرس سرویس Render، بدون `/` آخر (در مرحله بعد تنظیم می‌کنیم)

برای امنیت، توکن را داخل GitHub یا کد قرار نده.
